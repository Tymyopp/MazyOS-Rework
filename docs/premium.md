# Modelo open source × oferta comercial

Como o MazyOS se organiza entre o que é livre e o que é comercial — pra usuários
e pra quem quer revender serviço.

## O que é open source (MIT — grátis)

O repositório inteiro: as 28 skills, a memória, os templates, os scripts e a documentação.
Você pode:
- Usar no seu negócio, quantas vezes quiser
- Modificar e adaptar
- Distribuir cópias (mantendo o aviso de copyright e a licença)
- **Operar clientes com o sistema** (uso comercial do software é permitido)

## O que o site oficial vende (mazzeoia.com.br)

- Acesso com **aulas** (como aplicar cada skill no seu nicho)
- **Templates avançados** e exemplos de clientes reais
- **Suporte** direto e comunidade
- Conveniência do pacote pronto

Isso é serviço/educação, não o código — o código continua livre.

## Pra quem revende serviço (agências)

Você pode (e deve) usar o MazyOS pra entregar marketing pra clientes. Regras práticas:

| Ação | Permitido? |
|---|---|
| Usar as skills pra produzir pro cliente | ✅ sim |
| Cobrar pelo seu serviço (não pelo software) | ✅ sim |
| Repassar o repo como "produto seu" sem atribuição | ⚠️ MIT exige manter o aviso de copyright |
| Vender curso "aprenda MazyOS" em paralelo ao autor | ⚠️ verifique com o autor (mazzeoia.com.br) |

## Licença em uma frase

MIT: use, modifique, distribua — com atribuição e sem garantia (o software é "no estado em que está").
